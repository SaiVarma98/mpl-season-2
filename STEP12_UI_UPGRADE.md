# MPL Season 2 — Step 12 UI Upgrade

This build focuses on the four live-event observations:

1. SOLD presentation clearly shows the winning team and final price.
2. Player photography uses responsive, contain-style presentation so supplied
   photos are not aggressively cropped.
3. Auctioneer controls are visually compact, with secondary controls grouped
   away from the primary bidding workflow.
4. Viewer styling is upgraded with MPL/village-cricket broadcast backgrounds,
   richer overlays, and stronger SOLD presentation.

No auction business rules or API contracts are intentionally changed.

Included backgrounds:
- static/media/backgrounds/stadium_night.svg
- static/media/backgrounds/village_cricket.svg
- static/media/backgrounds/gold_particles.svg

No tests or Python cache files are included in this event build.
